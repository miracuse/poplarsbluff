# Endorsed Modules

The modules in this section are those that I have personally played through and would recommend to others without reservation.


| Name                                | Description                               |
| :---------------------------------- | :---------------------------------------- |
| Against the Cult of the Reptile God | A swords and sorcery expedition.          |
| Bloodright                          | An open-ended city exploration.           |
| Eye of the Beholder                 | An old-school subterranean dungeon crawl. |
| Siege of Shadowdale                 | A classic zero to hero adventure.         |
| Swordflight                         | A proper CRPG challenge for veterans.     |
| The Lord of Terror 2                | A superb quality Diablo remake.           |
| The Lost Caverns of Tsojcanth       | A pen-and-paper classic brought to life.  |
