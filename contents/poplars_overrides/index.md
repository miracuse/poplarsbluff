# Poplar's Overrides

{: .summary}
> A drop-in mod for changing how classes and races work.

### Overview

*Poplar's Overrides* is a set of tweaks for the original campaigns. It changes the behavior of classes and races, offering a different experience for players.

v0.0.1 - Under Testing
{: .label .label-yellow }

### Installation

* [Latest Download](../assets/overrides/poplars_overrides_v_0_1_0.zip)
* [Neverwinter Vault Link](https://neverwintervault.org/users/poplarsbluff)
* [NWN Wiki on Overrides](https://nwn.fandom.com/wiki/Override)

#### Instructions

    Download the zip file and extract it.
    Place the contents in your override folder.
    (Windows) You can find the override folder at "My Documents\Neverwinter Nights\override".
    (Linux) You can find the override folder at "~/.local/share/Neverwinter Nights/override".

#### Warnings, Caveats, Etc.

    Review the wiki article on overrides.
    Always create a new save when experimenting with overrides.
    Modules with custom content may not work with overrides.
    Not for use on multiplayer servers or with other online content.
