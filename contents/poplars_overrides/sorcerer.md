**Hit Die**: d6

**Proficiencies**: armor (light), weapons (simple) 

**Skill Points**: 2 + int modifier ( (2 + int modifier) * 4 at 1st level)   

**BaB Progression**: +1/2 / level (Low)  

**Skill List**: concentration, craft armor, craft trap, craft weapon, heal, lore, spellcraft, *persuasion*, *bluff*, *intimidate*

**Special**: animal companion options have been added to the familiars list, Shifter class changed to allow Sorcerer as a prerequisite
