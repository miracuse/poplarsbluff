# Spells

### Wizard/Sorcerer

* Simple Magic
  * Burning Hands is now Evocation.
  * Mage Armor is now Abjuration.
  * Persistent Blade is now Transmutation.
  * Darkness is now Illusion.
  * Acid Arrow is now Evocation.
  * Web is now Transmutation.
  * Flame Weapon is now Transmutation.
  * Clarity is now Divination.
  * Flame Arrow is now Transmutation.

* Intermediate Magic
  * Elemental Shield is now Abjuration.

* Necromancy
  * Animate Dead has been lowered to a third-level spell.
  * Create Undead has been lowered to a sixth-level spell.
  * Create Greater Undead has been added as a ninth-level spell.

* Shadow Magic
  * Shadow Conjuration, Greater Shadow Conjuration, and Shades sub-spells are now illusion spells.
  * Required spell level is dropped by one (i.e Shadow Conjuration is a third-level spell).

* Greater Transmutation
  * Unlocks Greater Bull's Strength (and similar) as sixth-level spells.
