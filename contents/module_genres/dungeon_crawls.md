# Dungeon Crawls

{: .summary}
> Adventures that focus on combat and survival. A good fit for players who want to test their skills and character builds.

| Name                                                                                                                            | Description                                                                  |
| :------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------- |
| [Swordflight](https://neverwintervault.org/project/nwn1/module/swordflight-chapter-one)                                         | A multi-chapter series with hardcore difficulty.                             |
| [Eye of the Beholder](https://neverwintervault.org/project/nwnee/module/eye-beholder)                                           | The definitive mega dungeon for Neverwinter Nights.                          |
| [Lord of Terror II](https://neverwintervault.org/project/nwnee/module/lord-terror-2)                                            | A very well-executed remake of Diablo with handy mechanics for auto-looting. |
| [Shadowlords/Dreamcatcher/Demon](https://neverwintervault.org/project/nwn1/module/shadowlords-dreamcatcher-and-demon-campaigns) | An episodic epic with its own mini-games.                                    |
